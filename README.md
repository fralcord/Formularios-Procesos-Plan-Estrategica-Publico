# Formularios de Procesos - Vista pública de revisión

Sitio de demostración de los formularios web de evaluación del Gobierno Regional de Los Lagos. Esta publicación contiene únicamente los formularios, recursos necesarios para ejecutarlos y datos ficticios de muestra. No incluye expedientes, oficios, planillas ni otros documentos de referencia.

## Abrir los formularios

Una vez que GitHub Pages termine el despliegue, abre el enlace del sitio y elige el formulario en el panel principal. No se requiere instalar software.

## Uso y privacidad

- Usa exclusivamente datos ficticios para revisar campos, orden, presentación y flujo.
- No ingreses ni compartas datos personales, información institucional reservada o antecedentes de casos reales.
- Los datos escritos en el navegador solo sirven para la demostración. La página no los guarda ni los envía a un servidor.
- La generación de JSON permite revisar la estructura del payload, pero no crea un registro en una base de datos.

## Enviar retroalimentación

En el panel principal, usa el enlace **Envía retroalimentación** o visita la pestaña **Issues** de este repositorio y elige **Retroalimentación sobre formularios**. Se requiere iniciar sesión en GitHub para enviar el comentario. Describe el formulario, la sección, lo observado y la mejora sugerida; usa datos ficticios.

## Contenido publicado

Se publican el panel, los cuatro formularios, estilos, scripts y esquemas de datos necesarios para la demostración. Los botones de ejemplo usan identificadores, nombres y antecedentes ficticios. Los materiales de referencia internos se mantienen fuera de este repositorio público.
